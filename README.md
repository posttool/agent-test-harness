# agent-test-harness

A harness for designing and testing a next-generation personal agent. It contains an LLM reasoning loop (Gemini **and** Claude), graph memory, tools the agent can discover, simulated ambient data, and a simulated phone Experience with Memory, Tools, Data and Traces panels for inspecting it.

- **[PLAN.md](PLAN.md)**: the full build plan (architecture, data model, testing strategy, milestones)
- **[docs/brief.md](docs/brief.md)**: the original "Agent OS - Quintessa" brief

Status: planning. The first milestone is the M0 scaffold (see PLAN.md §12).

# Liquid Glass: screens to design

## Discover

Add a "Discover" artboard to this canvas, in the same style as the existing screens (match Main.dc.html: same size, wallpaper, glass, type and tweaks).

Topics related to the user's interests and projects that they did not ask for.

It shows (use realistic sample copy; the harness replaces it with live data):
- discover rows: title, line, call to action, icon, badge

Taps:
- a row opens it (open)
- a row can be dismissed (dismiss)

Make sure it still reads well with:
- nothing to discover
- eight items

Repeated rows should be drawn as several real rows (three or four), each built the same way. Link it to the other artboards where a real phone would.
